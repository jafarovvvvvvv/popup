# Popup

Панель у верхнего края экрана для Windows 11. Порт [Cyclop](https://github.com/akalikbergenov/cyclop)
— приложения, которое превращает вырез MacBook в рабочую панель.

Невидима, пока курсор не подойдёт к верху экрана по центру. Раскрывается в
панель 620×208 с восемью вкладками: музыка, полка файлов, история буфера,
сниппеты, календарь, переводчик, заметки и вкладка разработки. Плюс столько
вкладок, сколько плагинов лежит в папке.

```bash
dotnet run --project src\Popup
```

## Что внутри

| Вкладка | Что делает | Чем отличается от macOS-оригинала |
|---|---|---|
| **Музыка** | Обложка, трек, play/pause/next, перемотка | Через системный SMTC — работает со Spotify, браузерами, VLC, Яндекс.Музыкой. Оригиналу ради этого приходилось грузить свою dylib в `/usr/bin/perl` |
| **Полка** | Перетащить файл на верх экрана, потом утащить в другое окно | Так же: хранятся ссылки, не копии |
| **Буфер** | Последние 40 копирований | Через `WM_CLIPBOARDUPDATE`, без опроса. Только в памяти, на диск не пишется |
| **Сниппеты** | Список заготовок, клик копирует | Тот же формат файла, что у оригинала |
| **Календарь** | Сетка месяца с листанием, встречи выбранного дня, кнопка входа в Zoom/Meet/Teams | У оригинала здесь только список ближайших встреч — в вырез MacBook сетка не влезала. Источник: ссылка на календарь или вход через Google, см. [docs/calendar.md](docs/calendar.md) |
| **Перевод** | EN↔RU, направление по алфавиту | Онлайн-провайдер вместо системного Translation.framework, которого в Windows нет |
| **Заметки** | Черновики, пустые исчезают сами | Так же |
| **Dev** | Живой журнал плагинов, перезагрузка, консоль | Своё — этого во вкладках оригинала нет |

## Живая активность

Третье состояние панели, которого нет у оригинала. Пока в системе что-то идёт —
запись голоса, сборка, загрузка — наверху висит узкая полоска: красная точка,
бегущая волна, таймер. Панель при этом не раскрывается и не закрывает работу.

Это то, во что превратилась пилюля **LocalWhisper**: когда Popup запущен, она
не показывает себя внизу справа, а отдаёт своё состояние наверх. Когда Popup
закрыт — работает как всегда. Ничего настраивать не надо, переключение на ходу.
Подробности — [docs/localwhisper.md](docs/localwhisper.md).

Говорить с панелью так может что угодно: она слушает `\\.\pipe\popup`, и любой
скрипт может показать активность, положить файл на полку, текст в буфер или
завести заметку. Протокол — [docs/pipe.md](docs/pipe.md).

## Первый запуск

Панель невидима, пока к ней не подвести курсор, — поэтому при первом запуске
показывается короткая карусель из четырёх страниц: где панель живёт, что в ней
есть, что такое полоска активности и как её достраивать. Больше она не
появится; чтобы позвать снова, поставь в `settings.json` `"onboardingShown": false`.

## Поведение панели

- Раскрывается, когда курсор **остановился** у верхнего края по центру. Мышь,
  пролетающая поперёк экрана, панель не открывает.
- Схлопывается через треть секунды после ухода курсора.
- Пока свёрнута — пропускает клики насквозь, не появляется в Alt-Tab и не
  забирает фокус. Полоска активности — тоже.
- `Ctrl+Alt+Space` показывает панель, когда руки уже на клавиатуре.
- В покое опрашивает курсор восемь раз в секунду и не делает больше ничего:
  ни таймеров, ни перерисовок.

Иконка в трее: показать панель, приватность по разделам, папки, автозапуск.

## Настройки

`%APPDATA%\Popup\settings.json` — создаётся при первом запуске.

```json
{
  "saveClipboardImages": true,
  "language": null,
  "toggleHotkey": "ctrl+alt+space",
  "translateProvider": "openai",
  "translateEndpoint": "https://api.openai.com/v1",
  "translateModel": "gpt-5.4-mini",
  "calendarIcsUrl": null
}
```

- `language` — `"ru"`, `"en"` или `null`. При `null` русский включается, если
  русская хотя бы одна из системных культур: Windows часто стоит с английским
  интерфейсом при русском регионе.
- `toggleHotkey` — запись как в LocalWhisper. Пусто — без клавиши.
- `calendarIcsUrl` — секретная ссылка на календарь. Самый короткий путь к
  встречам: без Google Cloud и без согласий. Подробности —
  [docs/calendar.md](docs/calendar.md).

Файл перечитывается на лету: поправил и сохранил — панель заметила, перезапуск
не нужен. Смена языка пересобирает панель, остальное применяется на месте.

Ключи (`translateApiKey`, `googleClientSecret`) вписываются открытым текстом и
там не задерживаются: при первом же чтении они переезжают в поля с суффиксом
`Enc` под DPAPI, а открытый текст из файла стирается.
- `translateProvider` — `openai` или `deepl`. Для локального перевода направьте
  `translateEndpoint` на Ollama: `http://localhost:11434/v1`.

Там же лежат `snippets.json` (правится руками), `notes.json`, `shelf.json`,
папки `Screenshots`, `plugins` и `logs`.

## Плагины

Своя вкладка — это папка в `%APPDATA%\Popup\plugins\` с `plugin.json` и
программой на чём угодно, которая читает строки JSON из stdin и пишет в stdout.
Полное описание протокола — [docs/plugins.md](docs/plugins.md).

В комплекте едут два рабочих:

- **Whisper** — последние расшифровки из локального Whisper, клик копирует.
- **Сервер** — что поднято на домашнем сервере: аптайм, память, список
  контейнеров. Только чтение, по уже настроенному SSH-ключу. Адрес правится в
  `plugins/homeserver/config.json`.

## Сборка и тесты

```bash
dotnet test
```

```bash
dotnet publish src\Popup -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

Нужен .NET 9 SDK. Панель — WPF, `net9.0-windows10.0.19041.0`: версия Windows в
таргете включает проекцию WinRT, на которой держится вкладка музыки.

Тесты покрывают то, что должно ломаться на сборке, а не на экране: геометрию в
двух системах координат, разбор чужих сообщений из канала, правила смены
полоски, форматирование времени и угадывание иконок сниппетов.
